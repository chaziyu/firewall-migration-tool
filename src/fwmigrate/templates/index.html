WORKSPACE GUIDE

From configuration to next step.

Choose the workflow that fits your task. You can use a backup file or retrieve configuration from a supported device.

  1. 01
    Convert configuration

    Select a source and target, upload a backup, then download a migration bundle with configuration artifacts and reports.

  2. 02
    Extract to Excel

    Download a source inventory workbook. For FortiGate interfaces, the Interfaces and Interface Source Settings sheets contain normalized fields and additional source settings.

  3. 03
    Live migration

    Configure the target connection, run diagnostics, then generate and review a plan. Applying changes requires your explicit confirmation.

{{ icon('info') }}A downloaded workbook is a snapshot. Generate a new file whenever you change the source configuration.
